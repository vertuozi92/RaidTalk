# RaidTalk — экспериментальная тёмно-серая тема

Пользовательская CSS-тема для веб-версии [RaidTalk](https://app.raidtalk.ru/), предназначенная для установки через расширение [Stylus](https://github.com/openstyles/stylus).

Тема оформлена в графитовой палитре и постепенно дополнялась настройками отдельных элементов интерфейса.

## Особенности оформления

- Основной фон интерфейса — графитовый (`#303236`).
- Верхняя навигационная панель — более светлый графитовый оттенок (`#414449`).
- Тёмное оформление чата, боковых панелей, каналов, очереди и голосовой панели.
- Настроенные границы и состояния навигационных вкладок.
- Оформление кнопок очереди и кошелька, включая голубые акценты.
- Красная метка «пауза» и зелёная индикация говорящего.
- Неоновое оформление ника активного говорящего.
- Музыкальный фон сцены встроен непосредственно в CSS.
- Настроенные тёмные полосы прокрутки и разделители.

## Установка через Stylus

1. Установите расширение [Stylus](https://github.com/openstyles/stylus) для своего браузера.
2. Откройте [RaidTalk](https://app.raidtalk.ru/).
3. Нажмите значок Stylus и выберите создание нового стиля для сайта.
4. Откройте файл [RaidTalk-graphite-theme.css](./RaidTalk-graphite-theme.css) в этом репозитории.
5. Скопируйте CSS целиком и вставьте его в редактор Stylus.
6. Сохраните стиль и обновите страницу RaidTalk.

## Совместимость

Тема рассчитана на веб-интерфейс RaidTalk: https://app.raidtalk.ru/

Стили используют CSS-классы и структуру текущего интерфейса. Если разработчики RaidTalk изменят разметку или названия классов, отдельные эффекты могут перестать работать. После крупных обновлений сайта CSS может потребовать корректировки.
