# RaidTalk — Graphite Theme

Пользовательская графитовая тёмная тема оформления веб-интерфейса **RaidTalk** для расширения [Stylus](https://github.com/openstyles/stylus).

## Что входит

- Тёмная графитовая палитра для основных окон и панелей.
- Стилизация чата, списков, боковых панелей, диалогов и элементов управления.
- Более спокойные цвета фона, границ и текста для единого оформления.
- Дополнительный CSS-патч в конце файла, который переопределяет часть исходных цветов в тёмной теме.

## Установка

1. Установите расширение [Stylus](https://github.com/openstyles/stylus) для своего браузера.
2. Откройте [RaidTalk](https://app.raidtalk.ru/).
3. Нажмите на значок Stylus и выберите **«Управление»** или **«Написать стиль для этого сайта»**.
4. Откройте файл [RaidTalk-graphite-theme.css](./RaidTalk-graphite-theme.css), скопируйте его содержимое и вставьте в редактор Stylus.
5. Сохраните стиль и обновите страницу RaidTalk.

Если в интерфейсе RaidTalk доступен переключатель светлой/тёмной темы, включите тёмную тему: дополнительные переопределения в конце CSS привязаны к атрибуту `data-theme="dark"`.

## Совместимость

Стиль предназначен для веб-версии RaidTalk: https://app.raidtalk.ru/

Интерфейс сайта может меняться, поэтому отдельные CSS-селекторы со временем могут потребовать обновления. Перед установкой рекомендуется сохранить резервную копию собственных стилей Stylus.

Проект поддерживается автором репозитория. Если после обновления RaidTalk что-то отображается неправильно, создайте [Issue](../../issues) и приложите описание проблемы и скриншот.
